# Modernize the BAGO Agent Chat frontend

## Objective

Modernize the visual presentation of the chat-first BAGO Agentic Data Lab
frontend while preserving existing application behavior, accessible interaction,
agent/proposal flows, authorization boundaries, provider handling, and navigation.

## Scope

- Refine the global visual foundation and application shell.
- Improve the chat layout, sidebar, conversation library, messages, composer,
  proposal cards, and responsive behavior.
- Keep the existing React behavior and API contracts unchanged.

## Acceptance criteria

- The frontend builds successfully.
- Existing UI tests pass.
- The chat remains usable at desktop and mobile viewport widths.
- Keyboard focus and semantic interaction remain visible and usable.
- No chat, provider, authorization, or persistence behavior is weakened.
- The generated README is refreshed and its consistency check passes.
