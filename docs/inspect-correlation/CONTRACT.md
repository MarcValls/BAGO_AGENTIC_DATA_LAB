# Chat → Inspect correlation v1

Scope: new read-only GET /api/conversations/{conversation_id}/inspection; optional trace_id, execution_id, offset>=0, limit1..50. Persisted conversation assistant references.trace are authority for membership. No query by global latest/demo. Pagination enumerates unique trace references in message order, total/next_offset, without substituting another execution. Multiple traces without explicit selection returns selection_required; one trace can be selected automatically and visibly identified. No traces returns no_artifacts.

Envelope schema bago.chat.inspection.v1: conversation_id, revision, state, executions[{trace_id,message_id,execution_id|null}], total, offset,next_offset,selected|null. Selected includes trace_id,execution_id,message_id,state,trace|null,sha256|null,integrity(hash_verified|legacy_unverified|not_available),limitations. Only supplied local trace is returned; no synthetic summary/evaluation/authorization/receipts or decision bundle. Existing DecisionInspector and its binding checks remain unchanged. Demo artifacts are accessible only through explicit separately labelled historical demo choice.

Expected valid trace id ^trace-[a-f0-9]{16}$, execution_id bounded opaque safe identifier. File must be unlinked regular JSON under configured allowed chat/scan trace roots, <=2MiB, structure IDs/event_count/events valid, unique event IDs/sequences, same trace and optional execution match. Ref trace_sha256 if present must match bytes; missing legacy hash is always legacy_unverified, never retrospective verification. Duplicate ambiguous references, mismatched IDs/hash, broken parent links => invalid; missing file => unavailable; persistence_failed is not success. Other conversation trace =>404 with no payload. Unknown conversation=>404. New persisted chat/scan references include execution_id+trace_sha256 on successful write.

Frontend AgentChat notifies App of selected conversation/revision, clearing selection before load/change. Per-message Inspeccionar ejecución supplies trace_id, never another conversation ID inferred from trace. App defaults conversation source, no global artifact fetch until explicit demo choice; selection is retained outside Chat unmount. Conversation inspection component resets old payload synchronously when identity changes and uses request generation/abort checks against late responses. It renders pagination and explicit execution selection, integrity/missing/unsupported states honestly. Async conversation fetches must ignore stale responses after selection/owner change.

Acceptance: own fixture selection including historical496fac replay; another conversation/absent/modified/hash/duplicate/escape cases; multiple executions+pagination; no demo fallback on no artifacts; late old responses cannot render; App+Chat callbacks/button wire into actual component. No model/provider/browser execution in this task. User/parent explicitly authorized fullstack repair; original mission and104 runtime files preserved, CR-INSPECT-001 records successor scope.
