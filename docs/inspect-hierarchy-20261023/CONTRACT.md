# Inspect: sucesión explícita de RC4

La captura anotada del usuario solicita controles de fuente visualmente integrados, ID de conversación identificable y mayor jerarquía entre ejecución, traza e integridad. RC4 y su misión anterior conservan su identidad y aceptación; no acreditan estos cambios posteriores. El objetivo global Docker/escritura revisada/espacio sigue activo.

## IH01 · aceptación finita

1. Selector de fuente integrado en la cabecera, activo/hover/foco distinguibles y accesibilidad conservada. Es un selector de conjunto de datos; no inventar paneles ARIA. Demo sólo explícita, siempre identificada como histórica e independiente del chat.
2. Conversación con ID completo, monoespaciado, seleccionable, wrap en estrecho y copia explícita por usuario con feedback ES/EN y fallo honesto.
3. Cuatro métricas visibles; selector de ejecución separado de los campos ejecución/traza y badge de integridad. Hash comprobado no equivale a evaluación PASS. Códigos, hash y diagnósticos originales íntegros bajo detalles técnicos, sin duplicación confusa.
4. Mantener latest por defecto, cero/sin selector cuando no hay ejecución, rechazo de identidad ajena, errores/no disponible y contenido distinto por vista. Cambiar idioma no refetch ni altera identidad.
5. Reproducir el posible render de PresentationError objeto en la rama demo con prueba negativa. Si se confirma, usar errorMessage existente y fallback localizado sin modificar contratos backend.
6. Root observará en Brave visible fuente actual, identificación, ejecución predeterminada, histórico y estado estrecho acotado; no reabrir la matriz detenida por el usuario.

IH01 no modifica backend, permisos, shared tabs ni otras superficies. Pruebas focales, build y contrato de idioma con fuentes finales. Todo cambio compartido se registra en el handoff.

## IH02 / IH03

Empaquetar una candidata sucesora inequívoca desde snapshot explícito, sin sobrescribir ZIP/candidatas previas ni copiar proveedores. Comprobar desde una extracción nueva el frontend y sus rutas al mismo host, efectos visuales y correlación, conservando las capacidades de escritura cuyo código no cambió con identidad explícita y observación de recuperación. Generar README según AGENTS; colección no equivale a suite ejecutada. Verificación independiente antes de aplicar al canal8093; observación posterior por root. No promoción del agent.run genérico, proveedores externos ni envío WhatsApp.
