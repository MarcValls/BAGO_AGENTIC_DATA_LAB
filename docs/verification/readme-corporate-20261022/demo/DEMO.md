# BAGO: demostración nueva desde el chat

Identificador: BAGO-CHAT-DEMO-20261022.

## Política del ejemplo

Una entrega exprés con más de 24 horas de retraso permite devolver el coste del envío.
Una entrega con 24 horas exactas o menos no cumple ese criterio.

## Datos ficticios

Pedido DEMO-001: envío exprés, retraso de 30 horas, coste de envío de 6 euros.
Pedido DEMO-002: envío exprés, retraso de 12 horas, coste de envío de 4 euros.

Este archivo es un fixture sintético creado para la demostración del 22 de octubre de 2026.
No contiene clientes reales y no autoriza pagos, escrituras ni ejecución de comandos.
