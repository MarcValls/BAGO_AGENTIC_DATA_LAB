# Comprobar el footer de Modelos

1. Abre Configuración → Proveedores y modelos → Modelos activos.
2. Con una lista larga, desplaza los modelos: Guardar y Salir permanecen visibles abajo.
3. Cambiar casillas prepara un borrador; Guardar aplica la selección explícita.
4. Salir cierra Configuración y vuelve a la pantalla anterior sin guardar el borrador.
5. Al volver a Proveedores, se conserva el espacio de sus pestañas, estado y desplazamiento.

La prueba conservada utilizó 18 modelos sintéticos, una App real compilada y APIs locales interceptadas. Las comprobaciones de persistencia y restricciones se ejecutaron por separado contra el backend real con archivos aislados y proveedores de prueba. No acredita inferencia externa ni una instalación Electron final.
