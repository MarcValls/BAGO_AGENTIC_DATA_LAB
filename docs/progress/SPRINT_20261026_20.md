## Resultado

Se reparó el recorrido por el que el Chat general respondía que no podía leer un archivo aunque el usuario pidiera expresamente la herramienta de lectura y autorizara ese archivo.

- El clasificador de control puede seleccionar `workspace_read` como etapa de sólo lectura.
- Para peticiones explícitas que nombran un archivo y la herramienta de workspace, el host limita el lector a la ruta autorizada para ese envío. Si no hay permiso o la ruta no coincide, informa que no leyó nada.
- La etapa de lectura expone únicamente `read_workspace_file`, sin rutas de escritura ni herramientas `development_*`.
- El recibo incluye `total_lines` y `truncated` junto con el intervalo leído.
- La lectura de un único archivo se ejecutó desde la UI contra un proyecto sintético en Temp con `ollama-cloud/kimi-k2.6`.

La implementación del servidor fue authored externamente por Codex en esta candidata; no se afirma que el código se haya escrito mediante el chat de ADL. La ejecución live sí se hizo desde la interfaz de ADL.
