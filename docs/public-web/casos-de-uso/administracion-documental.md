# Administración: extracción documental

**Sector:** administración y finanzas. **Objetivo:** localizar documentos autorizados y preparar un extracto con referencias para revisión humana.

![Catálogo de capacidades documentales y requisitos.](../assets/screenshots-2026-10-26/02-capacidades-completa.png)

## Recorrido

1. Revisa en **Capacidades** las funciones documentales disponibles; por ejemplo `document_inventory`, `document_extract` y `document_relate`.
2. Configura el agente con las herramientas que necesite y un alcance claro.
3. En Workspace selecciona el proyecto/carpeta correcto. Autoriza únicamente los archivos necesarios en el turno de chat.
4. Pide inventario o extracción con citas de página/sección, sin alterar los originales.
5. Revisa discrepancias manualmente. Si hay que crear un informe, verifica el permiso de salida y aprueba expresamente la escritura.

**Salida sugerida:** listado de documentos, campos extraídos, referencia verificable y elementos dudosos. **Límite:** no equivale a auditoría, conciliación contable ni aprobación de pagos. Guía de escenario; no se ejecutó.
