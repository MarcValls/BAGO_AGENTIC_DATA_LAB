# Investigación de mercado: fuentes públicas

**Sector:** consultoría e investigación. **Objetivo:** preparar un resumen contrastable de servicios, posicionamiento o cambios publicados en fuentes accesibles.

![Chat general de BAGO5 sin conversación previa visible.](../assets/screenshots-2026-10-26/01-chat-orquestador.png)

## Recorrido

1. En Chat, define una pregunta acotada y aporta las URL públicas que quieres comparar.
2. Marca **Permitir lectura web pública** para ese turno y revisa el alcance antes de enviarlo.
3. Si interviene un agente guardado, comprueba que su tarea y herramientas correspondan al análisis; la selección del agente no concede permisos web por sí sola.
4. Contrasta las afirmaciones con **Fuentes web** y sus fechas/referencias; separa hechos publicados de inferencias.
5. Abre **Inspeccionar ejecución** para revisar la operación y su traza si existe.

**Salida sugerida:** tabla de afirmaciones, fuente, fecha y limitación. **Límite:** no usar para afirmar cobertura completa del mercado, asesoramiento legal o verificación de fuentes privadas. No se ejecutó este escenario al redactar la guía.
