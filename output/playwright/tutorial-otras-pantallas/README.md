# Recorrido por otras pantallas de BAGO

- Video: [tutorial-otras-pantallas.mp4](tutorial-otras-pantallas.mp4)
- Subtítulos: [tutorial-otras-pantallas.srt](tutorial-otras-pantallas.srt)
- Evidencia de capturas y texto de pantalla: [screen-capture-report.json](screen-capture-report.json)
- Verificación de reproducción/huella: [video-verification.json](video-verification.json)

El recorrido muestra Summary, Retrieval & Ontology, Authorization, Trace, Evaluation, Decision Inspector, Capabilities, Job History y Agent Runner. Las capturas se obtuvieron navegando la app local `http://127.0.0.1:8081` en modo lectura. La llamada de navegación solo consultó artefactos ya cargados y el endpoint de historial. No se lanzó una llamada al modelo.

Bruma Market es un cliente ficticio. PASS, sus conteos, trazas y recibos son artefactos de demostración; AWS Live consta como NOT_RUN. La traza del paquete es local. Job History mostró cero trabajos y Agent Runner señaló que la ejecución gobernada no está disponible.

Las imágenes `scene-*.png` contienen capturas reales de las pantallas con título de capítulo. El WAV y los WAV por capítulo se generaron localmente con la voz del sistema.
